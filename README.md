# AWS_GRC_FEDRAMP20x
An AWS security project focused on IAM, security solicies, and continuous monitoring aligned with FEDRAMP 20x requirements.
This project explores how AWS IAM security reviews and continous monitoring can be automated to support FEDRAMP 20x evidence collection and validation.
The goal is to identetify privledged access risks, track changes over time and generate new structured evidence for compliance review.
Target completion DEC 1st 2026 Status: planning and development
